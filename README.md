Token Radar ranks 178 pre-token protocols by implied value — TVL, seven-day growth, age with no token, and chain breadth — with a farm plan for each, a sortable and filterable dashboard, and a separate view for protocols whose token already trades. Node 22, standard library only, deterministic.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
